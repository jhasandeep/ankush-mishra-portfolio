# Sandeep Kumar Jha - Portfolio

Next.js (App Router) + Tailwind CSS v4 + Framer Motion.

- `npm run dev` - start locally on http://localhost:3000
- `npm run build && npm start` - production build

## Editing content
All text (projects, experience, skills, hero copy for company vs freelance visitors) lives in `src/data/portfolio.ts`.
The downloadable resume is `public/Sandeep-Kumar-Jha-Resume.pdf` - replace the file to update it.
